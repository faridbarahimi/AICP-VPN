AICP VPN 2.3.28 — maintenance revision r1 (versionCode 769)

This release adds the Global Telegram aggregate source and tightens proxy-sharing behavior:
- Add a Global feed to Source Finder and Multi-Location. The Android app fetches the published CDN snapshot and does not connect directly to Telegram.
- Keep Global profiles separate from country attribution; the existing qualification checks determine which profiles enter the usable Multi-Location pool.
- Add cache-busting and a Raw.Githack fallback for the public feed.
- Harden LAN proxy sharing permission and credential checks.
- Preserve authenticated accounts when deriving the HTTP inbound from the SOCKS listener.
