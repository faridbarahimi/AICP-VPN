AICP VPN 2.3.27 — maintenance revision r1 (versionCode 768)

This release hardens connection recovery and improves Smart Connect selection:
- Treat HTTP 404/410 from public configuration mirrors as terminal for that source, avoiding long retries against dead mirrors.
- Rank eligible candidates using the combined real-ping and measured-bandwidth score used by Smart Connect.
- Add bounded Xray health recovery with exponential backoff (30s, 60s, 120s, capped at 4 minutes) and a recovery budget of 3 attempts per 5-minute window.
- Show clear Persian/English recovery-failure feedback and explain when a speed test is rejected because no verified direct network is available.
- Refine the app typography and compact the home cards and spacing while preserving readable touch targets.

Android package: com.aicp.vpn
Minimum Android: 10 (API 29); target API 37.

Available APKs:
- arm64-v8a: most modern Android phones/tablets using 64-bit ARM.
- armeabi-v7a: older 32-bit ARM devices.
- x86_64: 64-bit Intel/AMD Android devices and compatible emulators.
- x86: 32-bit Intel Android devices/emulators.
- universal: single APK containing all four supported ABI splits; largest download.
